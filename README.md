Simulação de Posts — Estilo Instagram 📸
Exercício prático em Java simulando uma rede social simples com posts e comentários.

📖 Sobre o projeto
Criação de posts com título, conteúdo, curtidas, data e comentários — similar ao funcionamento básico de um feed de rede social.

🕐 O que pratiquei

Criação e uso de classes com atributos e métodos
Uso de ArrayList para armazenar comentários
Formatação de datas com SimpleDateFormat
Sobrescrita do método toString() com StringBuilder
Relacionamento entre classes (Post e Comment)
